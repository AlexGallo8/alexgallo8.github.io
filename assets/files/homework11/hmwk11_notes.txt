Under a bell distribution we can define probability density and study the density function between two points.
Prob(x, x+dx) = f(x)dx

    - Probability density (continuous)
    - Probability function (discrete)
    - CDF (Cumulative Distribution function): how much the function increase in an interval (x1, x2): F2-F1
    [while P(X1 < X < X2) = x1∫x2(f(x)dx)]
    Fundamental theorem of calcolous: F2 - F1 = x1∫x2(f(x)dx)

    F(x) = Pr(X <= x)
