## Introduction

While [Homework 7]({% post_url 2025-11-08-homework7 %}) explored discrete random walks with discrete steps and [Homework 10]({% post_url 2025-11-15-homework10 %}) introduced counting processes with discrete state space, **Homework 11** extends these concepts to a fundamentally different type of stochastic process: the **Brownian process** (also called **Brownian motion**). The Brownian process represents a generalization of random walks that operates in **continuous time with continuous state space**, where position can take any real value and time evolves smoothly.

## Problem Statement

### Brownian Motion in Continuous Time and Space

Consider a particle (or other entity) whose position evolves randomly over continuous time t ≥ 0. At each instant, the particle experiences infinitesimal random "kicks" that accumulate to produce continuous paths. Unlike discrete random walks:
- **State space:** ℝ (all real numbers, not just integers)
- **Time:** Continuous t ≥ 0 (not discrete steps)
- **Increments:** Infinitesimally small and normally distributed
- **Paths:** Continuous but nowhere differentiable

**Goal:** Simulate this process by:
1. Discretizing time into small intervals of width Δt
2. In each interval, adding a normally distributed increment N(0, σ²Δt)
3. Plotting position paths and analyzing statistical properties
4. Verifying convergence to theoretical Brownian motion

**Question:** How does this continuous process relate to the discrete random walk? What are the key properties that distinguish Brownian motion?

### Mathematical Formulation

**Time discretization:**
```
t₀ = 0, t₁ = Δt, t₂ = 2Δt, ..., tₙ = nΔt = T
where Δt = T/n
```

**Position increment in interval i:**
```
ΔXᵢ ~ N(0, σ²Δt)
(normally distributed with mean 0 and variance σ²Δt)
```

**Cumulative position at time T:**
```
X(T) = X₀ + ΔX₁ + ΔX₂ + ... + ΔXₙ = X₀ + Σᵢ₌₁ⁿ ΔXᵢ
```

**Standard Brownian motion (σ = 1, X₀ = 0):**
```
B(t) = N(0, t)
(normally distributed with mean 0 and variance t)
```

**As n → ∞ (Δt → 0):** This discrete approximation converges to continuous-time Brownian motion.

## Theoretical Background

### 2.1 From Discrete Random Walk to Brownian Motion

**Scaling relationship (key insight):**

In a symmetric random walk with n steps over interval [0,T]:
- Each step: ±1 with probability 1/2
- Time per step: Δt = T/n
- Position at time T: X(T) = sum of n ±1 steps

**To pass to continuous limit:**

Instead of ±1 steps, use increments:
```
ΔXᵢ ~ N(0, Δt)
```

This choice ensures:
1. **Independence:** Increments in different time intervals are independent
2. **Continuity:** With infinitesimal increments, paths become continuous
3. **Scaling:** Variance grows linearly with time: Var(X(t)) = t

**Central Limit Theorem role:**

The sum of many small independent normal increments remains normal (by CLT), but with variance that grows as t. This is the foundation of Brownian motion.

### 2.2 Brownian Motion: Definition and Properties

**Definition (Standard Brownian Motion):** A stochastic process {B(t), t ≥ 0} is a standard Brownian motion (Wiener process) if:

1. **B(0) = 0** (starts at origin)

2. **Independent increments:** For any times 0 ≤ t₁ < t₂ < t₃ < t₄:
   ```
   B(t₂) - B(t₁) is independent of B(t₄) - B(t₃)
   ```

3. **Stationary increments:** The distribution of B(t+s) - B(s) depends only on t, not on s

4. **Normal distribution:** For any t > 0:
   ```
   B(t) ~ N(0, t)
   P(B(t) ≤ x) = Φ(x/√t)
   ```
   where Φ is the standard normal CDF

5. **Continuous paths:** B(t) is continuous in t (with probability 1)

6. **Non-differentiability:** Paths are nowhere differentiable (unbounded variation)

**Equivalent infinitesimal characterization:**

For small Δt > 0:
```
ΔB(t) = B(t+Δt) - B(t) ~ N(0, Δt)
Cov(ΔB(s), ΔB(t)) = 0 for s ≠ t (independent increments)
```

### 2.3 Key Properties of Brownian Motion

**Property 1: Distribution at time t**
```
B(t) ~ N(0, t)
f_t(x) = (1/√(2πt)) · exp(-x²/(2t))
```

**Property 2: Expected value**
```
E[B(t)] = 0
```

**Property 3: Variance**
```
Var(B(t)) = t
```

**Property 4: Standard deviation scales as √t**
```
SD(B(t)) = √t
```

This is why we divide by √n in the Central Limit Theorem.

**Property 5: Covariance function**
```
Cov(B(s), B(t)) = min(s,t)
```

For s < t: The earlier and later positions share the common variability from 0 to s.

**Property 6: Increments are normal**
```
B(t) - B(s) ~ N(0, t-s) for s < t
```

**Property 7: Self-similarity**
```
If {B(t), t ≥ 0} is Brownian motion, then {c·B(t/c²), t ≥ 0} is also Brownian motion
```

This scaling property connects discrete and continuous formulations.

**Property 8: Quadratic variation**
```
[B,B](t) = lim_{Δt→0} Σᵢ (ΔBᵢ)² = t (deterministic!)
```

Unlike position which is random, the total squared variation equals time.

**Property 9: Reflection principle**
```
P(max_{0≤s≤t} B(s) ≥ a) = 2·P(B(t) ≥ a) for a > 0
```

**Property 10: Recurrence**
```
For 1D Brownian motion: returns to any point infinitely often with probability 1
(recurrent)
```

### 2.4 Geometric Brownian Motion (GBM)

**Modified Brownian motion with drift and scaling:**
```
dX(t) = μ·X(t)·dt + σ·X(t)·dB(t)
```

**Solution:**
```
X(t) = X₀·exp((μ - σ²/2)t + σB(t))
```

**Used in:** Stock price modeling, financial option pricing (Black-Scholes)

### 2.5 Connection to Random Walk and Poisson Process

| Aspect | HW7: Random Walk | HW10: Poisson | HW11: Brownian |
|--------|------------------|---------------|----------------|
| **Time** | Discrete steps | Continuous time | Continuous time |
| **State space** | Discrete {±1, ±2, ...} | Discrete {0,1,2,...} | Continuous ℝ |
| **Increments** | ±1 (deterministic) | 0 or +1 (Bernoulli) | Normal (infinitesimal) |
| **Distribution** | Transformed Binomial | Poisson | Normal |
| **Variance growth** | Linear: σ²n | Linear: λt | Linear: t |
| **Scaling** | Classical limit → Brownian | N/A | Self-similar |
| **Paths** | Piecewise constant | Step function | Continuous |
| **Applications** | Stock prices, signals | Event counting | Volatility, diffusion |

**Key transitions:**
- Random walk (discrete) → Brownian motion (continuous) via scaling
- Brownian motion → Poisson process (change to counting)
- All converge to normal distributions by CLT

## Methodology

### 3.1 Simulation Parameters

**Fixed parameters:**
- **T = 1:** Time interval (normalized to [0,1])
- **n = 5000:** Number of time steps
- **Δt = T/n = 0.0002:** Width of each step

**Variable parameters:**
- **σ (volatility):** Controls the magnitude of random increments
  - Low volatility: σ = 0.5 (gentle random motion)
  - Medium volatility: σ = 1.0 (standard Brownian motion)
  - High volatility: σ = 2.0 (large fluctuations)
- **n_simulations:** Number of independent realizations (e.g., 1000)
- **μ (drift):** For non-zero mean case (optional)

### 3.2 Implementation Strategy

**Step 1: Time discretization**
```
Create time grid: t = [0, Δt, 2Δt, ..., T]
```

**Step 2: Generate increments**

For each time step i:
```
ΔBᵢ ~ N(0, σ²Δt)
```

This uses the standard normal distribution scaled by √(σ²Δt).

**Step 3: Cumulative position**
```
B(tᵢ) = B(tᵢ₋₁) + ΔBᵢ
```

This produces a continuous path: position accumulates increments over time.

**Step 4: Multiple realizations**

Repeat steps 2-3 many times to get distribution of:
- B(T) (final position)
- B(t) at various times t
- Maximum and minimum positions
- Path statistics (range, extreme values)

**Step 5: Comparison with theory**
- Plot empirical distribution of B(T)
- Overlay theoretical N(0, σ²T) PDF
- Calculate sample mean and variance
- Compare with theoretical 0 and σ²T

### 3.3 Validation Checks

**Check 1: Mean**
```
E[B(T)] = 0
Sample mean should be close to 0
```

**Check 2: Variance**
```
Var(B(T)) = σ²T
Sample variance should be close to σ²T
```

**Check 3: Distribution shape**
```
Empirical histogram should match normal PDF
Histogram should be roughly bell-shaped and symmetric
```

**Check 4: Path properties**
```
Paths should be continuous but rough
Paths should cross zero frequently (recurrence)
No monotonic trend visible
```

**Check 5: Increments are normal**
```
Distribution of ΔB should be approximately N(0, σ²Δt)
Q-Q plot should follow diagonal
```

### 3.4 Visualization Strategy

**Plot 1: Sample paths**
- Show several realizations of B(t) vs t
- Display continuous path nature
- Illustrate random fluctuations and crossings

**Plot 2: Distribution at final time**
- Histogram of B(T) from many simulations
- Overlay theoretical N(0, σ²T) PDF
- Include mean and variance annotations

**Plot 3: Distribution at multiple times**
- Show how variance grows with time
- Compare B(t) distributions for t = 0.2, 0.5, 1.0
- Demonstrate scaling property

**Plot 4: Volatility comparison**
- Compare paths with different σ values
- Show how σ affects path roughness
- Compare final distributions

**Plot 5: Convergence with time step**
- Show convergence as Δt decreases (n increases)
- Demonstrate that finer discretization gives better approximation

**Plot 6: Maximum/minimum over [0,T]**
- Distribution of max{B(t), 0≤t≤T}
- Distribution of min{B(t), 0≤t≤T}
- Compare with reflection principle predictions

    import numpy as np
    import matplotlib.pyplot as plt
    import seaborn as sns
    import os
    from scipy.stats import norm, kstest, shapiro

    def simulate_brownian_motion(sigma, T, n_steps, mu=0):
        """
        Simulate a single realization of Brownian motion (or with drift).
        
        Parameters:
        -----------
        sigma : float
            Volatility parameter (standard deviation of increments)
        T : float
            Total time interval
        n_steps : int
            Number of time steps
        mu : float
            Drift parameter (default 0 for standard Brownian motion)
        
        Returns:
        --------
        times : ndarray
            Time grid [0, dt, 2dt, ..., T]
        positions : ndarray
            Position B(t) at each time point
        """
        dt = T / n_steps
        times = np.linspace(0, T, n_steps + 1)
        
        # Generate increments: N(mu*dt, sigma^2*dt)
        increments = np.random.normal(mu * dt, sigma * np.sqrt(dt), size=n_steps)
        
        # Cumulative sum starting at 0
        positions = np.concatenate([[0], np.cumsum(increments)])
        
        return times, positions

    def simulate_multiple_realizations(sigma, T, n_steps, n_sims, mu=0):
        """
        Generate multiple independent realizations of Brownian motion.
        
        Returns:
        --------
        times : ndarray
            Time grid
        all_paths : ndarray
            Array of shape (n_sims, n_steps+1) with sample paths
        final_positions : ndarray
            Final position B(T) for each realization
        """
        times = np.linspace(0, T, n_steps + 1)
        all_paths = np.zeros((n_sims, n_steps + 1))
        
        for i in range(n_sims):
            _, positions = simulate_brownian_motion(sigma, T, n_steps, mu)
            all_paths[i] = positions
        
        final_positions = all_paths[:, -1]
        
        return times, all_paths, final_positions

    def theoretical_normal_pdf(x, mean, variance):
        """
        Calculate theoretical normal PDF.
        """
        sigma = np.sqrt(variance)
        return (1 / (sigma * np.sqrt(2 * np.pi))) * np.exp(-(x - mean)**2 / (2 * variance))

    def plot_sample_paths(times, paths, sigma, T, n_paths_to_plot=50, 
                            output_dir='assets/images'):
        """
        Plot sample paths of Brownian motion.
        """
        os.makedirs(output_dir, exist_ok=True)
        
        fig, ax = plt.subplots(figsize=(14, 8))
        
        # Select subset of paths to plot
        n_total = paths.shape[0]
        indices = np.linspace(0, n_total - 1, min(n_paths_to_plot, n_total)).astype(int)
        
        for idx in indices:
            ax.plot(times, paths[idx], linewidth=0.8, alpha=0.7, color='steelblue')
        
        # Add mean path (should be near zero for standard Brownian)
        mean_path = np.mean(paths, axis=0)
        ax.plot(times, mean_path, 'r-', linewidth=3, label='Mean path')
        
        # Add ±1 SD envelope
        std_path = np.std(paths, axis=0)
        ax.fill_between(times, mean_path - std_path, mean_path + std_path,
                        alpha=0.2, color='red', label='±1 SD envelope')
        
        # Theoretical envelope: ±√t for standard BM
        if sigma == 1.0:
            ax.plot(times, np.sqrt(times), 'k--', linewidth=2, label='±√t bounds')
            ax.plot(times, -np.sqrt(times), 'k--', linewidth=2)
        
        ax.axhline(y=0, color='k', linestyle='-', alpha=0.3, linewidth=0.5)
        ax.set_xlabel('Time t', fontsize=13, fontweight='bold')
        ax.set_ylabel('Position B(t)', fontsize=13, fontweight='bold')
        ax.set_title(f'Brownian Motion Sample Paths (σ = {sigma}, T = {T})',
                    fontsize=14, fontweight='bold')
        ax.legend(fontsize=11)
        ax.grid(True, alpha=0.3)
        
        plt.tight_layout()
        filename = f'{output_dir}/hw11_sample_paths_sigma_{sigma:.1f}.png'
        plt.savefig(filename, dpi=300, bbox_inches='tight')
        print(f"Saved: {filename}")
        plt.close()

    def plot_final_position_distribution(final_positions, sigma, T, 
                                        output_dir='assets/images'):
        """
        Plot distribution of B(T) and compare with theoretical normal.
        """
        os.makedirs(output_dir, exist_ok=True)
        
        fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 7))
        
        # Theoretical parameters
        theoretical_var = (sigma ** 2) * T
        theoretical_std = np.sqrt(theoretical_var)
        
        # Left: Histogram with PDF overlay
        ax1.hist(final_positions, bins=50, density=True, alpha=0.6,
                color='steelblue', edgecolor='black', linewidth=1.5,
                label='Empirical')
        
        # Theoretical normal PDF
        x_range = np.linspace(final_positions.min(), final_positions.max(), 1000)
        pdf = theoretical_normal_pdf(x_range, 0, theoretical_var)
        ax1.plot(x_range, pdf, 'r-', linewidth=3,
                label=f'Theoretical N(0, {theoretical_var:.3f})')
        
        # Statistics
        sample_mean = np.mean(final_positions)
        sample_var = np.var(final_positions, ddof=1)
        
        stats_text = f'Sample mean: {sample_mean:.4f}\n'
        stats_text += f'Theoretical mean: 0.0000\n'
        stats_text += f'Sample variance: {sample_var:.4f}\n'
        stats_text += f'Theoretical variance: {theoretical_var:.4f}\n'
        stats_text += f'Sample std: {np.std(final_positions, ddof=1):.4f}\n'
        stats_text += f'Theoretical std: {theoretical_std:.4f}'
        
        ax1.text(0.98, 0.97, stats_text, transform=ax1.transAxes,
                fontsize=10, verticalalignment='top', horizontalalignment='right',
                bbox=dict(boxstyle='round', facecolor='wheat', alpha=0.8))
        
        ax1.set_xlabel('Position B(T)', fontsize=12, fontweight='bold')
        ax1.set_ylabel('Density', fontsize=12, fontweight='bold')
        ax1.set_title(f'Distribution of Final Position (σ = {sigma}, T = {T})',
                    fontsize=13, fontweight='bold')
        ax1.legend(fontsize=11)
        ax1.grid(True, alpha=0.3)
        
        # Right: Q-Q plot
        sorted_positions = np.sort(final_positions)
        n = len(sorted_positions)
        theoretical_quantiles = norm.ppf((np.arange(1, n + 1) - 0.5) / n, 
                                        loc=0, scale=theoretical_std)
        
        ax2.scatter(theoretical_quantiles, sorted_positions, alpha=0.5, s=20)
        
        # Perfect fit line
        min_val = min(theoretical_quantiles.min(), sorted_positions.min())
        max_val = max(theoretical_quantiles.max(), sorted_positions.max())
        ax2.plot([min_val, max_val], [min_val, max_val], 'r--', linewidth=2,
                label='Perfect fit')
        
        ax2.set_xlabel('Theoretical Quantiles (Normal)', fontsize=12, fontweight='bold')
        ax2.set_ylabel('Empirical Quantiles', fontsize=12, fontweight='bold')
        ax2.set_title('Q-Q Plot', fontsize=13, fontweight='bold')
        ax2.legend(fontsize=11)
        ax2.grid(True, alpha=0.3)
        
        plt.tight_layout()
        filename = f'{output_dir}/hw11_distribution_sigma_{sigma:.1f}.png'
        plt.savefig(filename, dpi=300, bbox_inches='tight')
        print(f"Saved: {filename}")
        plt.close()
        
        return sample_mean, sample_var

    def perform_normality_tests(final_positions, sigma, T):

## Mathematical Derivations

### 5.1 Scaling Property

**Brownian motion self-similarity:**

If B(t) is Brownian motion, then so is:
```
B̃(t) = c·B(t/c²)
```

**Proof:**
```
Var(B̃(t)) = c²·Var(B(t/c²))
          = c²·(t/c²)
          = t ✓
```

**Implication:** You can rescale time and space while preserving the Brownian motion property.

### 5.2 Variance Growth and the √t Law

**Central Limit Theorem applied to increments:**

After n steps with increment variance σ²Δt:
```
Var(X(T)) = n·Var(ΔX) = n·σ²Δt = n·σ²(T/n) = σ²T
```

This is why SD(X(T)) = σ√T, giving the characteristic √t scaling.

**Why divide by √n in CLT?**

For sum of n i.i.d. random variables:
```
Y = (Σᵢ Xᵢ)/√n ~ N(μ, σ²/n)
```

The divisor √n controls the variance, ensuring it doesn't grow to infinity.

### 5.3 Quadratic Variation

**Key property distinguishing Brownian motion:**

For sample paths, compute:
```
[B,B](t) = lim_{Δt→0} Σᵢ (B(tᵢ₊₁) - B(tᵢ))²
```

**Result:** [B,B](t) = t (deterministic!)

**Implication:** While individual increments are random, their squared sum equals time with probability 1. This is crucial for stochastic calculus (Itô's lemma).

### 5.4 Connection to Random Walk

**Donsker's Invariance Principle:**

Consider a symmetric random walk:
```
Sₙ = X₁ + X₂ + ... + Xₙ
where Xᵢ ~ ±1 with equal probability
```

Rescaled random walk:
```
B̃ₙ(t) = Sₙ₍ₜₙ₎ / √n
```

**As n → ∞:**
```
B̃ₙ(t) →^d B(t) (convergence in distribution)
```

The discrete random walk, when properly scaled and rescaled in time, converges to Brownian motion.

## Applications and Extensions

### 6.1 Financial Applications

**Stock price modeling:**

Classical geometric Brownian motion (Black-Scholes):
```
dS(t) = μ·S(t)·dt + σ·S(t)·dB(t)
```

where:
- S(t) = stock price
- μ = drift (expected return)
- σ = volatility
- B(t) = Brownian motion

Solution:
```
S(t) = S₀·exp((μ - σ²/2)t + σB(t))
```

### 6.2 Physics Applications

**Diffusion processes:**

Heat equation and random particle movement modeled by Brownian motion

**Brownian particles:**

Dust particles, pollen, molecules in fluid - exhibit Brownian motion due to random molecular collisions

### 6.3 Biology

**Neurotransmitter diffusion:** Random walk of molecules across synapses

**Population genetics:** Allele frequency changes modeled by Brownian motion

### 6.4 Generalizations

**Multi-dimensional Brownian motion:**
```
B(t) = (B₁(t), B₂(t), ..., Bₐ(t))
where each component is independent Brownian motion
```

**Correlated Brownian motions:**
```
dX(t) = ρ·dB(t)
dY(t) = √(1-ρ²)·dB(t)
with correlation ρ
```

**Ornstein-Uhlenbeck process:**
```
dX(t) = -θ·X(t)·dt + σ·dB(t)
(Brownian motion with mean reversion)
```

   - Stochastic calculus (Itô's lemma)
