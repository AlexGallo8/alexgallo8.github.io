## Introduction

While **Homework 7** explored symmetric random walks with discrete steps (+1/-1), **Homework 10** introduces a fundamentally different type of stochastic process: the **counting process**. Instead of tracking position in a bidirectional walk, we count the number of events (arrivals, occurrences) that happen over continuous time. This homework demonstrates how discretizing continuous time leads to one of the most important processes in probability theory: the **Poisson process**.

<!--more-->

## Problem Statement

### Counting Process in Continuous Time

Consider a time interval [0, T] (e.g., T = 1 hour, 1 day, etc.) during which "events" or "successes" occur. These events:
- Occur **independently** of each other
- Are **uniformly distributed** in time (no preferred moments)
- Happen at a constant **average rate λ** (events per unit time)

**Goal:** Simulate this process by:
1. Dividing [0, T] into n small subintervals of width Δt = T/n
2. In each subinterval, an event occurs with probability λ·Δt
3. Counting the total number of events N(T) in the interval

**Question:** What stochastic process does this approximate? What are its theoretical properties?

### Mathematical Formulation

**Time discretization:**
```
t₀ = 0, t₁ = Δt, t₂ = 2Δt, ..., tₙ = nΔt = T
where Δt = T/n
```

**Event indicator in subinterval i:**
```
Xᵢ ~ Bernoulli(p = λΔt)
Xᵢ = 1 with probability λΔt (event occurs)
Xᵢ = 0 with probability 1-λΔt (no event)
```

**Total count at time T:**
```
N(T) = X₁ + X₂ + ... + Xₙ = Σᵢ₌₁ⁿ Xᵢ
```

**As n → ∞ (Δt → 0):** This discrete approximation converges to a continuous-time counting process.

## Theoretical Background

### 2.1 From Discrete to Continuous: The Limiting Process

**Key Observation:** As we take finer subdivisions (n → ∞), we have:
- Each subinterval becomes infinitesimally small: Δt → 0
- The probability of an event in any subinterval becomes tiny: λΔt → 0
- But the expected number of events remains constant: E[N(T)] = nλΔt = λT

**What does N(T) approximate?**

Since N(T) = Σᵢ₌₁ⁿ Xᵢ where Xᵢ ~ Bernoulli(λΔt), we have:
```
N(T) ~ Binomial(n, p = λΔt = λT/n)
```

As n → ∞ with λT fixed, this binomial distribution converges to:
```
N(T) ~ Poisson(λT)
```

**This is a Poisson process!**

### 2.2 The Poisson Process: Definition and Properties

**Definition (Poisson Process):** A counting process {N(t), t ≥ 0} is a Poisson process with rate λ > 0 if:

1. **N(0) = 0** (starts at zero)

2. **Independent increments:** For any times 0 ≤ t₁ < t₂ < t₃ < t₄:
   ```
   N(t₂) - N(t₁) is independent of N(t₄) - N(t₃)
   ```

3. **Stationary increments:** The distribution of N(t+s) - N(s) depends only on t, not on s

4. **Poisson distribution:** For any t > 0:
   ```
   N(t) ~ Poisson(λt)
   P(N(t) = k) = e^(-λt) · (λt)^k / k!
   ```

**Equivalent characterization (infinitesimal properties):**

For small Δt > 0:
```
P(N(t+Δt) - N(t) = 1) = λΔt + o(Δt)
P(N(t+Δt) - N(t) = 0) = 1 - λΔt + o(Δt)
P(N(t+Δt) - N(t) ≥ 2) = o(Δt)
```

where o(Δt) represents terms that vanish faster than Δt as Δt → 0.

**Interpretation:** In a small time interval Δt:
- Exactly one event occurs with probability ≈ λΔt
- No events occur with probability ≈ 1 - λΔt
- Multiple events are negligible (probability goes to zero faster)

### 2.3 Key Properties of the Poisson Process

**Property 1: Distribution at time t**
```
P(N(t) = k) = e^(-λt) · (λt)^k / k!
```

**Property 2: Expected value**
```
E[N(t)] = λt
```

**Property 3: Variance**
```
Var(N(t)) = λt
```

**Property 4: Mean and variance are equal** (characteristic of Poisson)

**Property 5: Interarrival times**

The time between consecutive events follows an exponential distribution:
```
T₁, T₂, T₃, ... ~ Exponential(λ)
f(t) = λe^(-λt), t ≥ 0
E[Tᵢ] = 1/λ
```

**Property 6: Arrival times**

The time of the k-th event follows a Gamma distribution:
```
Sₖ = T₁ + T₂ + ... + Tₖ ~ Gamma(k, λ)
```

**Property 7: Memoryless property**

Knowing that no event occurred until time s doesn't change the distribution of waiting time for the next event.

**Property 8: Superposition**

If N₁(t) ~ PP(λ₁) and N₂(t) ~ PP(λ₂) are independent Poisson processes, then:
```
N(t) = N₁(t) + N₂(t) ~ PP(λ₁ + λ₂)
```

**Property 9: Thinning**

If events from PP(λ) are independently kept with probability p, the result is PP(pλ).

### 2.4 The Rate Parameter λ

**Physical interpretation:** λ is the average number of events per unit time.

**Units:** 
- If T is in hours and λ = 5, expect 5 events per hour
- If T is in seconds and λ = 0.1, expect 0.1 events per second (1 event per 10 seconds)

**Scaling:** 
- In interval [0, t], expect λt events
- Mean interarrival time is 1/λ

**Examples:**
- λ = 10 customers/hour → Average of 10 customers per hour, 20 in 2 hours
- λ = 0.5 failures/day → Average of 0.5 failures per day, 1 failure every 2 days
- λ = 100 particles/second → Average of 100 particle detections per second

### 2.5 Connection to Random Walk (Homework 7)

| Aspect | Homework 7 (Random Walk) | Homework 10 (Poisson Process) |
|--------|-------------------------|------------------------------|
| **Type** | Position process | Counting process |
| **Time** | Discrete steps | Continuous time |
| **State space** | {..., -2, -1, 0, 1, 2, ...} | {0, 1, 2, 3, ...} |
| **Steps** | ±1 (bidirectional) | +1 only (non-decreasing) |
| **Distribution** | Transformed Binomial | Poisson |
| **Parameters** | p (step probability) | λ (rate) |
| **Path behavior** | Up/down fluctuations | Monotone increasing jumps |
| **Applications** | Price movements, signals | Arrivals, failures, calls |

**Key difference:** Random walk can go up or down; Poisson process only counts up (number of events is non-decreasing).

## Methodology

### 3.1 Simulation Parameters

**Fixed parameters:**
- **T = 1:** Time interval (normalized to [0,1])
- **n = 5000:** Number of subintervals
- **Δt = T/n = 0.0002:** Width of each subinterval

**Variable parameters:**
- **λ:** Rate parameter (events per unit time)
  - Small rate: λ = 1 (expect 1 event in [0,1])
  - Medium rate: λ = 10 (expect 10 events)
  - Large rate: λ = 50 (expect 50 events)
- **n_simulations:** Number of independent realizations (e.g., 1000)

### 3.2 Implementation Strategy

**Step 1: Time discretization**
```
Create time grid: t = [0, Δt, 2Δt, ..., T]
```

**Step 2: Generate events**

For each subinterval i:
```
Xᵢ ~ Bernoulli(λΔt)
```

This gives a sequence of 0s and 1s indicating when events occur.

**Step 3: Cumulative counting**
```
N(t) = cumulative sum of X₁, X₂, ..., Xₜ/Δₜ
```

This produces a step function: N(t) stays constant, then jumps by 1 when an event occurs.

**Step 4: Multiple realizations**

Repeat steps 2-3 many times to get distribution of:
- N(T) (total count)
- N(t) at various times t
- Interarrival times

**Step 5: Comparison with theory**
- Plot empirical distribution of N(T)
- Overlay theoretical Poisson(λT) PMF
- Calculate sample mean and variance
- Compare with theoretical λT

### 3.3 Validation Checks

**Check 1: Mean**
```
E[N(T)] = λT
Sample mean should be close to λT
```

**Check 2: Variance**
```
Var(N(T)) = λT
Sample variance should be close to λT
```

**Check 3: Distribution shape**
```
Empirical histogram should match Poisson PMF
```

**Check 4: Interarrival times**
```
If we record times between events, they should follow Exponential(λ)
```

### 3.4 Visualization Strategy

**Plot 1: Sample paths**
- Show several realizations of N(t) vs t
- Display step function nature
- Illustrate randomness in jump times

**Plot 2: Distribution of N(T)**
- Histogram of final counts from many simulations
- Overlay theoretical Poisson(λT) PMF
- Include mean and variance annotations

**Plot 3: Convergence analysis**
- Show how distribution changes with n (fineness of subdivision)
- Demonstrate convergence to Poisson as n increases

**Plot 4: Rate parameter effects**
- Compare processes with different λ values
- Show how λ affects both count and variability

**Plot 5: Interarrival times** (optional)
- Histogram of time differences between events
- Overlay theoretical Exponential(λ) PDF

   import numpy as np
   import matplotlib.pyplot as plt
   import seaborn as sns
   import os
   from scipy.stats import poisson, expon, chi2_contingency, kstest
   from scipy.special import factorial

   def simulate_poisson_process(lambda_rate, T, n_intervals):
      """
      Simulate a single realization of a Poisson process.
      
      Parameters:
      -----------
      lambda_rate : float
         Rate parameter (expected events per unit time)
      T : float
         Total time interval
      n_intervals : int
         Number of subintervals to divide [0,T]
      
      Returns:
      --------
      times : ndarray
         Time grid [0, dt, 2dt, ..., T]
      counts : ndarray
         Cumulative count N(t) at each time point
      """
      dt = T / n_intervals
      times = np.linspace(0, T, n_intervals + 1)
      
      # Generate events: Bernoulli(lambda*dt) for each interval
      events = np.random.binomial(1, lambda_rate * dt, size=n_intervals)
      
      # Cumulative sum gives the counting process
      counts = np.concatenate([[0], np.cumsum(events)])
      
      return times, counts

   def simulate_multiple_realizations(lambda_rate, T, n_intervals, n_sims):
      """
      Generate multiple independent realizations of the Poisson process.
      
      Returns:
      --------
      times : ndarray
         Time grid
      all_paths : ndarray
         Array of shape (n_sims, n_intervals+1) with sample paths
      final_counts : ndarray
         Final count N(T) for each realization
      """
      times = np.linspace(0, T, n_intervals + 1)
      all_paths = np.zeros((n_sims, n_intervals + 1))
      
      for i in range(n_sims):
         _, counts = simulate_poisson_process(lambda_rate, T, n_intervals)
         all_paths[i] = counts
      
      final_counts = all_paths[:, -1]
      
      return times, all_paths, final_counts

   def theoretical_poisson_pmf(lambda_t, k_max):
      """
      Calculate theoretical Poisson PMF.
      
      Parameters:
      -----------
      lambda_t : float
         Parameter λt for Poisson(λt)
      k_max : int
         Maximum k value to compute
      
      Returns:
      --------
      k_values : ndarray
         Array [0, 1, 2, ..., k_max]
      probabilities : ndarray
         P(N = k) for each k
      """
      k_values = np.arange(0, k_max + 1)
      probabilities = poisson.pmf(k_values, lambda_t)
      
      return k_values, probabilities

   def plot_sample_paths(times, paths, lambda_rate, T, n_paths_to_plot=50, 
                        output_dir='assets/images'):
      """
      Plot sample paths of the Poisson process.
      """
      os.makedirs(output_dir, exist_ok=True)
      
      fig, ax = plt.subplots(figsize=(14, 8))
      
      # Select subset of paths to plot
      n_total = paths.shape[0]
      indices = np.linspace(0, n_total - 1, min(n_paths_to_plot, n_total)).astype(int)
      colors = plt.cm.viridis(np.linspace(0, 1, len(indices)))
      
      for idx, path_idx in enumerate(indices):
         ax.step(times, paths[path_idx], where='post', 
                  color=colors[idx], alpha=0.6, linewidth=1.5)
      
      # Add mean trajectory
      mean_path = np.mean(paths, axis=0)
      ax.plot(times, mean_path, 'r-', linewidth=3, 
            label=f'Mean trajectory (E[N(t)] = {lambda_rate}t)')
      
      # Theoretical mean
      ax.plot(times, lambda_rate * times, 'k--', linewidth=2.5,
            label=f'Theoretical mean: λt = {lambda_rate}t')
      
      ax.set_xlabel('Time t', fontsize=13, fontweight='bold')
      ax.set_ylabel('Count N(t)', fontsize=13, fontweight='bold')
      ax.set_title(f'Poisson Process Sample Paths (λ = {lambda_rate}, T = {T})', 
                  fontsize=14, fontweight='bold')
      ax.legend(fontsize=11)
      ax.grid(True, alpha=0.3)
      
      plt.tight_layout()
      filename = f'{output_dir}/hw10_sample_paths_lambda_{lambda_rate:.1f}.png'
      plt.savefig(filename, dpi=300, bbox_inches='tight')
      print(f"Saved: {filename}")
      plt.close()

   def plot_final_count_distribution(final_counts, lambda_rate, T, 
                                    output_dir='assets/images'):
      """
      Plot distribution of N(T) and compare with theoretical Poisson.
      """
      os.makedirs(output_dir, exist_ok=True)
      
      fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 7))
      
      # Left: Histogram with PMF overlay
      lambda_t = lambda_rate * T
      k_max = int(max(final_counts)) + 5
      k_theory, p_theory = theoretical_poisson_pmf(lambda_t, k_max)
      
      # Empirical histogram
      counts, bins, _ = ax1.hist(final_counts, bins=range(int(min(final_counts)), 
                                 int(max(final_counts)) + 2), 
                                 density=True, alpha=0.6, color='steelblue',
                                 edgecolor='black', linewidth=1.5,
                                 label='Empirical')
      
      # Theoretical PMF
      ax1.plot(k_theory, p_theory, 'ro-', linewidth=2.5, markersize=8,
               label=f'Theoretical Poisson({lambda_t:.1f})')
      
      # Statistics
      sample_mean = np.mean(final_counts)
      sample_var = np.var(final_counts, ddof=1)
      
      stats_text = f'Sample mean: {sample_mean:.3f}\n'
      stats_text += f'Theoretical mean: {lambda_t:.3f}\n'
      stats_text += f'Sample variance: {sample_var:.3f}\n'
      stats_text += f'Theoretical variance: {lambda_t:.3f}\n'
      stats_text += f'Variance/Mean ratio: {sample_var/sample_mean:.3f}'
      
      ax1.text(0.98, 0.97, stats_text, transform=ax1.transAxes,
               fontsize=10, verticalalignment='top', horizontalalignment='right',
               bbox=dict(boxstyle='round', facecolor='wheat', alpha=0.8))
      
      ax1.set_xlabel('Count N(T)', fontsize=12, fontweight='bold')
      ax1.set_ylabel('Probability', fontsize=12, fontweight='bold')
      ax1.set_title(f'Distribution of Final Count (λ = {lambda_rate}, T = {T})',
                  fontsize=13, fontweight='bold')
      ax1.legend(fontsize=11)
      ax1.grid(True, alpha=0.3)
      
      # Right: Q-Q plot
      # Sort empirical quantiles
      sorted_counts = np.sort(final_counts)
      n = len(sorted_counts)
      empirical_quantiles = (np.arange(1, n + 1) - 0.5) / n
      
      # Theoretical quantiles from Poisson
      theoretical_quantiles = poisson.ppf(empirical_quantiles, lambda_t)
      
      ax2.scatter(theoretical_quantiles, sorted_counts, alpha=0.5, s=20)
      
      # Perfect fit line
      min_val = min(theoretical_quantiles.min(), sorted_counts.min())
      max_val = max(theoretical_quantiles.max(), sorted_counts.max())
      ax2.plot([min_val, max_val], [min_val, max_val], 'r--', linewidth=2,
               label='Perfect fit')
      
      ax2.set_xlabel('Theoretical Quantiles (Poisson)', fontsize=12, fontweight='bold')
      ax2.set_ylabel('Empirical Quantiles', fontsize=12, fontweight='bold')
      ax2.set_title('Q-Q Plot', fontsize=13, fontweight='bold')
      ax2.legend(fontsize=11)
      ax2.grid(True, alpha=0.3)
      
      plt.tight_layout()
      filename = f'{output_dir}/hw10_distribution_lambda_{lambda_rate:.1f}.png'
      plt.savefig(filename, dpi=300, bbox_inches='tight')
      print(f"Saved: {filename}")
      plt.close()
      
      return sample_mean, sample_var

   def analyze_interarrival_times(paths, times, lambda_rate, T,
                                 output_dir='assets/images'):
      """
      Extract and analyze interarrival times.
      """
      os.makedirs(output_dir, exist_ok=True)
      
      interarrival_times = []
      
      for path in paths:
         # Find jump times (where count increases)
         jumps = np.where(np.diff(path) > 0)[0]
         if len(jumps) > 1:
               jump_times = times[jumps]
               # Calculate time differences
               diffs = np.diff(jump_times)
               interarrival_times.extend(diffs)
      
      if len(interarrival_times) == 0:
         print("No interarrival times found (too few events)")
         return
      
      interarrival_times = np.array(interarrival_times)
      
      fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 7))
      
      # Left: Histogram with exponential overlay
      ax1.hist(interarrival_times, bins=50, density=True, alpha=0.6,
               color='steelblue', edgecolor='black', linewidth=1.5,
               label='Empirical')
      
      # Theoretical exponential
      t_range = np.linspace(0, max(interarrival_times), 1000)
      ax1.plot(t_range, expon.pdf(t_range, scale=1/lambda_rate),
               'r-', linewidth=3, label=f'Exponential(λ={lambda_rate})')
      
      sample_mean = np.mean(interarrival_times)
      theoretical_mean = 1 / lambda_rate
      
      stats_text = f'Sample mean: {sample_mean:.4f}\n'
      stats_text += f'Theoretical mean: {theoretical_mean:.4f}\n'
      stats_text += f'Sample size: {len(interarrival_times)}'
      
      ax1.text(0.97, 0.97, stats_text, transform=ax1.transAxes,
               fontsize=11, verticalalignment='top', horizontalalignment='right',
               bbox=dict(boxstyle='round', facecolor='wheat', alpha=0.8))
      
      ax1.set_xlabel('Interarrival Time', fontsize=12, fontweight='bold')
      ax1.set_ylabel('Density', fontsize=12, fontweight='bold')
      ax1.set_title(f'Interarrival Time Distribution (λ = {lambda_rate})',
                  fontsize=13, fontweight='bold')
      ax1.legend(fontsize=11)
      ax1.grid(True, alpha=0.3)
      
      # Right: Q-Q plot
      sorted_times = np.sort(interarrival_times)
      n = len(sorted_times)
      empirical_quantiles = (np.arange(1, n + 1) - 0.5) / n
      theoretical_quantiles = expon.ppf(empirical_quantiles, scale=1/lambda_rate)
      
      ax2.scatter(theoretical_quantiles, sorted_times, alpha=0.5, s=20)
      
      min_val = min(theoretical_quantiles.min(), sorted_times.min())
      max_val = max(theoretical_quantiles.max(), sorted_times.max())
      ax2.plot([min_val, max_val], [min_val, max_val], 'r--', linewidth=2,
               label='Perfect fit')
      
      ax2.set_xlabel('Theoretical Quantiles (Exponential)', fontsize=12, fontweight='bold')
      ax2.set_ylabel('Empirical Quantiles', fontsize=12, fontweight='bold')
      ax2.set_title('Q-Q Plot for Interarrival Times', fontsize=13, fontweight='bold')
      ax2.legend(fontsize=11)

   def perform_statistical_tests(final_counts, lambda_rate, T):
      """
      Perform statistical tests for Poisson fit.
      """
      lambda_t = lambda_rate * T
      
      # Chi-square goodness of fit
      unique_counts, observed_freq = np.unique(final_counts, return_counts=True)
      
      # Expected frequencies
      k_min, k_max = int(min(unique_counts)), int(max(unique_counts))
      k_range = np.arange(k_min, k_max + 1)
      expected_prob = poisson.pmf(k_range, lambda_t)
      expected_freq = expected_prob * len(final_counts)
      
      # Match observed to expected
      observed_aligned = np.zeros(len(k_range))
      for i, k in enumerate(k_range):
         if k in unique_counts:
               idx = np.where(unique_counts == k)[0][0]
               observed_aligned[i] = observed_freq[idx]
      
      # Remove bins with expected frequency < 5
      valid = expected_freq >= 5
      if np.sum(valid) > 1:
         chi2_stat = np.sum((observed_aligned[valid] - expected_freq[valid])**2 / 
                           expected_freq[valid])
         dof = np.sum(valid) - 1 - 1  # -1 for constraint, -1 for estimated parameter
         from scipy.stats import chi2
         p_value = 1 - chi2.cdf(chi2_stat, dof)
         
         print("\nChi-Square Goodness-of-Fit Test:")
         print(f"  χ² statistic: {chi2_stat:.4f}")
         print(f"  Degrees of freedom: {dof}")
         print(f"  p-value: {p_value:.4f}")
         print(f"  Result: {'PASS' if p_value > 0.05 else 'FAIL'} (α=0.05)")
      else:
         print("\nChi-Square test: Insufficient data for valid test")
      
      # KS test
      ks_stat, ks_pval = kstest(final_counts, 'poisson', args=(lambda_t,))
      print("\nKolmogorov-Smirnov Test:")
      print(f"  KS statistic: {ks_stat:.4f}")
      print(f"  p-value: {ks_pval:.4f}")
      print(f"  Result: {'PASS' if ks_pval > 0.05 else 'FAIL'} (α=0.05)")

## Mathematical Derivations

### 5.1 Binomial → Poisson Convergence

**Setup:** Let N ~ Binomial(n, p) with np = λ (constant)

As n → ∞ and p → 0 with np = λ fixed:
```
P(N = k) = C(n,k) p^k (1-p)^(n-k)
         = [n!/(k!(n-k)!)] · (λ/n)^k · (1-λ/n)^(n-k)
```

**Step 1:** Simplify factorials
```
n!/(n-k)! = n(n-1)(n-2)...(n-k+1) → n^k as n → ∞
```

**Step 2:** Binomial coefficient
```
C(n,k)/n^k = n(n-1)...(n-k+1)/(k!·n^k) → 1/k! as n → ∞
```

**Step 3:** Exponential term
```
(1-λ/n)^n → e^(-λ) as n → ∞
(1-λ/n)^(-k) → 1 as n → ∞
```

**Result:**
```
P(N = k) → e^(-λ) · λ^k / k! = Poisson(λ) PMF
```

### 5.2 Properties from Infinitesimal Analysis

**Setup:** Divide [0,T] into n intervals of width Δt = T/n

**Probability of event in one interval:**
```
p = P(event in [t, t+Δt]) = λΔt + o(Δt)
```

**Number of events in [0,T]:**
```
N(T) ~ Binomial(n, p)
E[N(T)] = np = n · λT/n = λT
Var(N(T)) = np(1-p) ≈ np = λT (since p → 0)
```

**Taking limit n → ∞:**
```
N(T) → Poisson(λT)
```

### 5.3 Memoryless Property

**Exponential distribution of interarrival times:**

Given that no event has occurred until time s, the remaining wait time has the same distribution:
```
P(T > s+t | T > s) = P(T > t)
```

**Proof:**
```
P(T > s+t | T > s) = P(T > s+t) / P(T > s)
                    = e^(-λ(s+t)) / e^(-λs)
                    = e^(-λt)
                    = P(T > t)
```

This is why the Poisson process has "no memory" of past events.

### 6.2 Extensions and Generalizations

**Non-homogeneous Poisson process:**

Rate varies with time: λ(t) instead of constant λ
```
E[N(t)] = ∫₀ᵗ λ(s)ds
```

**Compound Poisson process:**

Each event has an associated random "size" Yᵢ:
```
X(t) = Σᵢ₌₁^N(t) Yᵢ
```

Example: Total insurance claims (number of claims × claim amounts)

**Spatial Poisson process:**

Events distributed in space (not just time):
- Points randomly distributed in a region
- λ = intensity (expected points per unit area/volume)

**Cox process (doubly stochastic):**

Rate λ is itself a random process:
```
N(t) | Λ(t) ~ PP(Λ(t))
```

### 6.3 Relationship to Other Processes

**Connection to exponential distribution:**
- Poisson counts events in fixed time
- Exponential gives time until next event
- They are "dual" to each other

**Connection to Gamma distribution:**
- Time until k-th event: Gamma(k, λ)
- Sum of k exponential random variables

**Connection to normal distribution:**
- For large λt, Poisson(λt) ≈ Normal(λt, λt)
- Central Limit Theorem applies

**Continuous-time Markov chain:**
- Poisson process is the simplest example
- State space: {0, 1, 2, 3, ...}
- Transition: only from n to n+1, rate λ
