## Introduction to the Law of Large Numbers

The **Law of Large Numbers (LLN)** is one of the fundamental theorems in probability theory and statistics. It provides the theoretical foundation for why we can estimate probabilities through repeated experiments and why sample averages converge to expected values.

In this homework, I explore the LLN through simulation and visualization, demonstrating how the relative frequency of successes in repeated Bernoulli trials converges to the true underlying probability as the number of trials increases.

<!--more-->

## Theoretical Background

### What is the Law of Large Numbers?

The Law of Large Numbers states that as the number of independent trials of a random experiment increases, the sample average converges to the expected value.

**Formal Statement (Weak Law of Large Numbers):**

Let X₁, X₂, ..., Xₙ be independent and identically distributed (i.i.d.) random variables with expected value E[Xᵢ] = μ and finite variance Var(Xᵢ) = σ². Define the sample mean:

```
f(n) = (X₁ + X₂ + ... + Xₙ) / n
```

Then, for any ε > 0:

```
lim P(|f(n) - μ| > ε) = 0
n→∞
```

This means that the probability that f(n) deviates from μ by more than ε approaches zero as n increases.

### Bernoulli Trials and Relative Frequency

For this simulation, we focus on **Bernoulli trials**:
- Each trial has two outcomes: success (1) or failure (0)
- Probability of success: p
- Probability of failure: 1 - p
- Trials are independent

The **relative frequency** after n trials is:

```
f(n) = (number of successes) / n
```

According to the LLN, as n → ∞, f(n) → p (almost surely).

### Key Properties

**1. Convergence Rate:**

The variance of f(n) is:

```
Var(f(n)) = p(1-p) / n
```

This shows that the spread of f(n) around p decreases proportionally to 1/√n.

**2. Central Limit Theorem Connection:**

For large n, the distribution of f(n) is approximately normal:

```
f(n) ~ N(p, p(1-p)/n)
```

**3. Confidence Intervals:**

With probability ≈ 0.95, f(n) lies within:

```
p ± 1.96 × √(p(1-p)/n)
```

## Methodology

### Simulation Parameters

For this analysis, I simulated the LLN with the following parameters:

- **p**: Probability of success (tested with p = 0.5 and p = 0.3)
- **n**: Number of trials per trajectory (ranging from 50 to 1000)
- **m**: Number of independent trajectories (typically 30-50)

### Implementation Strategy

The simulation follows these steps:

1. **Generate Random Trials**: For each of m trajectories, generate n Bernoulli trials with success probability p

2. **Calculate Relative Frequencies**: For each trajectory, compute the cumulative relative frequency:
   ```
   f(k) = (X₁ + X₂ + ... + Xₖ) / k, for k = 1, 2, ..., n
   ```

3. **Visualization**: 
   - Plot all m trajectories on the same graph
   - Add a horizontal line at y = p (the true probability)
   - Create a histogram of the final frequencies f(n) for all trajectories

4. **Statistical Analysis**: Compute mean, standard deviation, and compare to theoretical predictions

### Python Implementation

The complete implementation is provided in `lln_simulation.py`:

**Key Functions:**

```python
def simulate_lln(p, n, m):
    """
    Simulate the Law of Large Numbers.
    
    Parameters:
    - p: true probability of success
    - n: number of trials per trajectory
    - m: number of trajectories
    
    Returns:
    - trajectories: array of shape (m, n) with relative frequencies
    """
    trials = np.random.binomial(1, p, size=(m, n))
    cumulative_successes = np.cumsum(trials, axis=1)
    trial_numbers = np.arange(1, n + 1)
    trajectories = cumulative_successes / trial_numbers
    return trajectories
```

2. True probability reference line (red dashed)
3. Side histogram showing distribution at n trials

## Mathematical Deep Dive

### Proof Sketch (Weak LLN via Chebyshev's Inequality)

**Given**: X₁, ..., Xₙ i.i.d. with E[Xᵢ] = μ, Var(Xᵢ) = σ²

**Define**: f(n) = (X₁ + ... + Xₙ) / n

**Properties**:
```
E[f(n)] = μ
Var(f(n)) = σ²/n
```

**Chebyshev's Inequality**:
```
P(|f(n) - μ| ≥ ε) ≤ Var(f(n)) / ε² = σ² / (nε²)
```

**As n → ∞**:
```
lim P(|f(n) - μ| ≥ ε) ≤ lim σ²/(nε²) = 0
n→∞                        n→∞
```

Therefore: f(n) → μ in probability.

### Connection to Central Limit Theorem

The **Central Limit Theorem (CLT)** strengthens the LLN by describing the *distribution* of f(n):

```
√n × (f(n) - p) → N(0, p(1-p))  as n → ∞
```

Equivalently:
```
f(n) ~ N(p, p(1-p)/n)  for large n
```

This explains why our histograms become bell-shaped as n increases.

### Convergence Types

| Type | Definition | Strength |
|------|------------|----------|
| Almost Sure | P(lim f(n) = p) = 1 | Strongest |
| In Probability | P(\|f(n)-p\| > ε) → 0 | Medium |
| In Distribution | F_n → F | Weakest |

The LLN guarantees convergence **in probability**. The **Strong LLN** guarantees **almost sure convergence**.

## Comparison with Other Statistical Concepts

### LLN vs Central Limit Theorem

| Aspect | Law of Large Numbers | Central Limit Theorem |
|--------|---------------------|----------------------|
| **What it tells us** | Sample mean → population mean | Distribution of sample mean |
| **Mathematical statement** | f(n) → p | √n(f(n)-p) → N(0,σ²) |
| **Practical use** | "Average stabilizes" | "Construct confidence intervals" |
| **Conditions** | Finite variance | Finite variance |
| **Result type** | Convergence | Distributional limit |

### LLN in Different Contexts

**Casino "Law of Averages" (Common Misconception)**:
- ❌ Wrong: "I've lost 10 times, so I'm due to win"
- ✓ Right: "Over millions of bets, my win rate approaches the house probability"

**The Gambler's Fallacy**:

The LLN does NOT imply that early deviations are "corrected" by opposite deviations. Instead, early deviations become proportionally negligible as n increases.

Example with fair coin:
- First 10 flips: 8 heads, 2 tails (80% heads)
- Next 990 flips: 495 heads, 495 tails (50% heads)
- Total 1000 flips: 503 heads, 497 tails (50.3% heads) ✓

The "excess" 6 heads from early flips persists, but becomes negligible (0.6% deviation).

## Computational Considerations

### Algorithm Efficiency

**Naive Approach** (compute each f(k) independently):
```
Time: O(m × n²)
Space: O(m × n)
```

**Optimized Approach** (use cumulative sums):
```
Time: O(m × n)
Space: O(m × n)
```

Our implementation uses NumPy's vectorized operations:

```python
trials = np.random.binomial(1, p, size=(m, n))        # O(mn)
cumulative = np.cumsum(trials, axis=1)                # O(mn)
frequencies = cumulative / np.arange(1, n+1)         # O(mn)
```
