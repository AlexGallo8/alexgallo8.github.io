## Introduction: Two Perspectives on Binary Random Processes

[Homework 4]({% post_url 2025-10-28-homework4 %}) and [Homework 7]({% post_url 2025-11-08-homework7 %}) explored two fundamental ways to model sequences of binary random outcomes. While both involve independent trials with two possible results, they differ profoundly in their mathematical structure, interpretation, and applications. This homework provides a comprehensive comparison, highlighting the deep connections between these seemingly different processes.

**Core Question:** What changes when we shift from counting successes (Homework 4) to tracking signed displacements (Homework 7)?

<!--more-->

## Side-by-Side Comparison

### Basic Setup

| Aspect | Homework 4: Bernoulli Process | Homework 7: Random Walk |
|--------|-------------------------------|------------------------|
| **Process Name** | Law of Large Numbers Simulation | Symmetric/Asymmetric Random Walk |
| **Trial Outcome** | Success (1) or Failure (0) | Step Up (+1) or Step Down (-1) |
| **Cumulative Quantity** | Number of successes: k | Net displacement: s = 2k - n |
| **Range After n Trials** | k ∈ {0, 1, 2, ..., n} | s ∈ {-n, -n+2, ..., n-2, n} |
| **Possible Values** | n + 1 values | n + 1 values (same parity as n) |
| **Starting Point** | k = 0 | s = 0 |
| **Direction** | Monotone increasing (k ≥ 0) | Bidirectional (s can be negative) |

### Mathematical Formulation

**Homework 4 (Bernoulli Process):**
```
Xᵢ ∈ {0, 1}
K(n) = Σ Xᵢ  (total successes)
E[K(n)] = np
Var[K(n)] = np(1-p)
```

**Homework 7 (Random Walk):**
```
Yᵢ ∈ {-1, +1}
S(n) = Σ Yᵢ  (net displacement)
E[S(n)] = n(q-p') = n(2q-1)
Var[S(n)] = 4nqp'
```

where q = P(Yᵢ = +1) and p' = P(Yᵢ = -1) = 1-q.

### The Fundamental Transformation

The two processes are related by a simple transformation:
```
S(n) = 2K(n) - n
K(n) = (n + S(n)) / 2
```

**Example:** After n=10 trials with k=7 successes:
- Homework 4: Position k = 7
- Homework 7: Score s = 2(7) - 10 = 4

This transformation:
- **Maps** [0, n] → [-n, n]
- **Stretches** the range by factor of 2
- **Centers** around 0 instead of n/2
- **Preserves** the combinatorial structure

### Visualization Differences

**Homework 4 Trajectories:**
```
f(t) = K(t) / t  (relative frequency)
```
- Trajectories start at variable points (0 or 1)
- Converge toward horizontal line at p
- Always bounded: 0 ≤ f(t) ≤ 1
- Focus: convergence behavior

**Homework 7 Trajectories:**
```
S(t) = 2K(t) - t  (cumulative score)
```
- All trajectories start at 0
- Can wander above and below starting point
- Unbounded: -t ≤ S(t) ≤ t
- Focus: path structure and excursions

## Mathematical Connections

### 1. Binomial Coefficients: The Unifying Structure

Both processes use the same counting mechanism:

**Number of paths reaching position k (HW4) or score s (HW7):**
```
N(n, k) = C(n, k) = n! / (k!(n-k)!)
```

For Homework 7, score s corresponds to k = (n+s)/2 successes:
```
N(n, s) = C(n, (n+s)/2)
```

**Example (n=6):**

| k (HW4) | s (HW7) | Paths C(6,k) |
|---------|---------|--------------|
| 0 | -6 | 1 |
| 1 | -4 | 6 |
| 2 | -2 | 15 |
| 3 | 0 | 20 |
| 4 | +2 | 15 |
| 5 | +4 | 6 |
| 6 | +6 | 1 |

**Observation:** Same combinatorial structure, different interpretation:
- HW4: "How many ways to choose k successes from 6 trials?"
- HW7: "How many paths reach score s after 6 steps?"

### 2. Pascal's Triangle: The Universal Structure

Both homeworks generate Pascal's triangle, but read it differently:

**Pascal's Triangle (n=0 to n=6):**
```
                    1
                  1   1
                1   2   1
              1   3   3   1
            1   4   6   4   1
          1   5  10  10   5   1
        1   6  15  20  15   6   1
```

**Homework 4 Reading (row n=6):**
- Position k: Number of ways to get exactly k successes in 6 trials
- Values: {1, 6, 15, 20, 15, 6, 1} for k ∈ {0,1,2,3,4,5,6}

**Homework 7 Reading (row n=6):**
- Position s: Number of paths reaching score s after 6 steps
- Values: {1, 6, 15, 20, 15, 6, 1} for s ∈ {-6,-4,-2,0,2,4,6}

**The mapping:** Same numbers, stretched coordinate system (s = 2k - n).

### 3. Recurrence Relations

Both satisfy the same fundamental recurrence:

**Combinatorial Form:**
```
C(n, k) = C(n-1, k-1) + C(n-1, k)
```

**Homework 4 Interpretation:**
"To have k successes in n trials, either:
- Last trial was success, and we had k-1 successes in first n-1 trials, OR
- Last trial was failure, and we had k successes in first n-1 trials"

**Homework 7 Interpretation:**
```
N(n, s) = N(n-1, s-1) + N(n-1, s+1)
```
"To reach position s at step n, we must have been at:
- Position s-1 at step n-1 and moved up (+1), OR
- Position s+1 at step n-1 and moved down (-1)"

**Graphical representation:**
```
        Step n-1          Step n
           •  (s+1)
            \
             \  (-1 step)
              ↘
               •  (s)
              ↗
             /  (+1 step)
            /
           •  (s-1)
```

### 4. Binomial Distribution Connection

**Homework 4:** Direct binomial distribution
```
P(K = k) = C(n,k) p^k (1-p)^(n-k)
```

**Homework 7:** Transformed binomial distribution
```
P(S = s) = P(K = (n+s)/2) = C(n, (n+s)/2) q^((n+s)/2) p'^((n-s)/2)
```

where:
- K = number of +1 steps (successes)
- S = 2K - n (net displacement)
- k = (n+s)/2 relates the two

**Distribution shape:**
- Both are binomial distributions
- HW7 is HW4 stretched and centered at 0
- Same bell curve, different x-axis scale

### 5. Binomial Expansion

The binomial theorem provides the foundation for both:
```
(A + B)^n = Σ(k=0 to n) C(n,k) A^k B^(n-k)
```

**Setting A = B = 1:**
```
2^n = Σ C(n,k)
```

**Interpretation:**
- **Total trajectories:** 2^n (each of n steps has 2 choices)
- **Sum of all path counts:** Σ C(n,k) = 2^n ✓

**Homework 4:** 2^n total sequences of n binary outcomes
**Homework 7:** 2^n total random walk paths through n steps

**Example (n=5):**
```
2^5 = 32 = C(5,0) + C(5,1) + C(5,2) + C(5,3) + C(5,4) + C(5,5)
        = 1 + 5 + 10 + 10 + 5 + 1
```

### 6. Fibonacci Sequence Connection

Hidden within Pascal's triangle are the Fibonacci numbers, obtained by summing diagonals:
```
                    1
                  1   1
                1   2   1
              1   3   3   1
            1   4   6   4   1
          1   5  10  10   5   1
        1   6  15  20  15   6   1

Diagonal sums:
F(1) = 1
F(2) = 1 + 1 = 1
F(3) = 1 + 2 = 2
F(4) = 1 + 3 + 1 = 3
F(5) = 1 + 4 + 3 = 5
F(6) = 1 + 5 + 6 + 1 = 8
F(7) = 1 + 6 + 10 + 4 = 13
```

**Formula:**
```
F(n) = Σ(k=0 to ⌊n/2⌋) C(n-k-1, k)
```

**Connection to our homeworks:**
- Fibonacci appears when counting paths with constraints
- Example: Number of ways to reach position n using steps of size 1 or 2
- Related to lattice paths, which generalize both HW4 and HW7 structures

### 7. Symmetry Properties

**Homework 4 (p = 0.5):**
```
P(K = k) = P(K = n-k)
C(n,k) = C(n, n-k)
```
Distribution is symmetric around k = n/2.

**Homework 7 (q = p' = 0.5):**
```
P(S = s) = P(S = -s)
N(n,s) = N(n,-s)
```
Distribution is symmetric around s = 0.

**Asymmetry:** When p ≠ 0.5 (HW4) or q ≠ p' (HW7):
- HW4: Distribution skews toward larger k if p > 0.5
- HW7: Random walk drifts positive if q > p', negative if q < p'

| Aspect | Homework 4 | Homework 7 |

| **Central Question** | "What proportion of trials succeed?" | "Where do we end up?" |
| **Accumulation** | One-directional (counting up) | Bidirectional (up and down) |
| **Focus** | Convergence to probability | Path behavior and position |
| **Key Theorem** | Law of Large Numbers | Random Walk Theory |
| **Application** | Frequency estimation | Position tracking |

### 2. Range and Scale

**Homework 4:**
- Range: [0, n]
- n+1 possible values
- Relative frequency: f(n) = k/n ∈ [0, 1]

**Homework 7:**
- Range: [-n, n]
- n+1 possible values (same parity)
- Score: s ∈ {-n, -n+2, ..., n-2, n}

**Scale transformation:** s = 2k - n maps HW4 → HW7

### 3. Visualization Differences

**Homework 4 plots:**
```
f(n) vs n (relative frequency over trials)
- Trajectories converge to horizontal line at p
- Y-axis: [0, 1]
- Shows LLN convergence behavior
```

**Homework 7 plots:**
```
S(n) vs n (cumulative score over steps)
- Trajectories start at origin, wander up/down
- Y-axis: [-n, n]
- Shows random walk structure
```

### 4. Statistical Interpretation

**Homework 4:**
```
Mean: E[K] = np
Variance: Var[K] = np(1-p)
Distribution: K ~ Binomial(n, p)
```

**Homework 7:**
```
Mean: E[S] = n(q-p') = n(2q-1)
Variance: Var[S] = 4nqp'
Distribution: S ~ 2·Binomial(n, q) - n
```

**Expected position:**
- HW4: Expected successes = np
- HW7: Expected score = n(q-p')
  - If q = p' = 0.5: E[S] = 0 (symmetric walk)
  - If q > p': E[S] > 0 (positive drift)
  - If q < p': E[S] < 0 (negative drift)

### 5. Probability Calculations

**Homework 4:** P(exactly k successes)
```
P(K = k) = C(n,k) p^k (1-p)^(n-k)
```

**Homework 7:** P(final score = s)
```
P(S = s) = C(n, (n+s)/2) q^((n+s)/2) p'^((n-s)/2)
```

**Example (n=10, p=0.6 → q=0.6, p'=0.4):**

| k (HW4) | P(K=k) | s (HW7) | P(S=s) |
|---------|--------|---------|--------|
| 0 | 0.0001 | -10 | 0.0001 |
| 5 | 0.2007 | 0 | 0.2007 |
| 8 | 0.1209 | +6 | 0.1209 |
| 10 | 0.0060 | +10 | 0.0060 |

Same probabilities, different coordinate systems!

2. **Game Theory:**

**Key insight:** Random walks model cumulative effects of balanced forces.

## Convergence Behavior

### Homework 4: Convergence to Probability

**Law of Large Numbers:**
```
f(n) = K/n → p  as n → ∞
```

**Rate of convergence:**
```
Var[f(n)] = p(1-p)/n → 0  as n → ∞
```

**Central Limit Theorem:**
```
√n (f(n) - p) → N(0, p(1-p))
```

**Practical meaning:** 
- With 1000 trials, f(1000) ≈ p ± 0.03 (roughly)
- Uncertainty decreases as 1/√n

### Homework 7: Spreading Distribution

**Expected position:**
```
E[S(n)] = n(q - p')
```

**Standard deviation:**
```
σ[S(n)] = 2√(nqp')
```

**Central Limit Theorem:**
```
(S(n) - n(q-p')) / (2√(nqp')) → N(0, 1)
```

**Practical meaning:**
- Position spreads as √n
- Even with drift, substantial randomness remains
- After 1000 steps: typical deviation ≈ 30 steps from expected position

## Combined Visualization

To see the relationship, we can plot both perspectives simultaneously:

**Example: n=100, p=0.6 (or q=0.6, p'=0.4)**
```python
import numpy as np
import matplotlib.pyplot as plt

n = 100
p = 0.6
trajectories = np.random.binomial(1, p, size=(50, n))

# Homework 4: Cumulative successes
K = np.cumsum(trajectories, axis=1)
f_n = K / np.arange(1, n+1)

# Homework 7: Random walk (transform 0→-1, 1→+1)
steps = 2 * trajectories - 1
S = np.cumsum(steps, axis=1)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(16, 6))

# Plot HW4
for i in range(50):
    ax1.plot(range(1, n+1), f_n[i], alpha=0.5)
ax1.axhline(p, color='red', linewidth=2, label=f'p={p}')
ax1.set_title('Homework 4: Relative Frequency')
ax1.set_xlabel('Trial n')
ax1.set_ylabel('f(n) = K/n')
ax1.legend()
ax1.grid(True, alpha=0.3)

# Plot HW7
for i in range(50):
    ax2.plot(range(1, n+1), S[i], alpha=0.5)
ax2.axhline(0, color='red', linewidth=2, label='Starting position')
ax2.axhline(n*(2*p-1), color='orange', linewidth=2, 
           linestyle='--', label=f'Expected: {n*(2*p-1):.0f}')
ax2.set_title('Homework 7: Random Walk Score')
ax2.set_xlabel('Step n')
ax2.set_ylabel('S(n)')
ax2.legend()
ax2.grid(True, alpha=0.3)

plt.tight_layout()
plt.show()
```

## Deep Mathematical Connections

### 1. Generating Functions

**Binomial coefficients generating function:**
```
(1 + x)^n = Σ(k=0 to n) C(n,k) x^k
```

**Applications:**
- Extract C(n,k) as coefficient of x^k
- Proves identities like Σ C(n,k) = 2^n (set x=1)
- Connects to probability generating functions

### 2. Catalan Numbers

Related to Pascal's triangle via:
```
Cat(n) = C(2n, n) / (n+1)
```

**Connection to random walks:**
- Catalan numbers count paths that never go below starting point
- "Ballot problem": paths where cumulative score stays ≥ 0
- Appears in HW7 when adding boundary constraints

### 3. Stirling's Approximation

For large n:
```
C(n, n/2) ≈ 2^n / √(πn/2)
```

**Implications:**
- Central binomial coefficient (most probable outcome)
- Both HW4 and HW7 peak probabilities
- Explains bell curve shape in histograms

### 4. Reflection Principle

**Random walk theorem:**
Number of paths from (0,0) to (n,k) that touch or cross y=-1:
```
= Number of paths from (0,-2) to (n,k)
```

**Application:** Calculate probability of first return to origin, hitting boundaries, etc.

## Conclusion

Homeworks 4 and 7 explore the same fundamental combinatorial structure—the binomial distribution—from two complementary perspectives:

**Homework 4 (Bernoulli Process):**
- **Counts** successes: "How many heads?"
- **Converges** to probability via LLN
- **Application:** Estimating rates and proportions
- **Range:** [0, n], monotone increasing

**Homework 7 (Random Walk):**
- **Tracks** net displacement: "How far up or down?"
- **Wanders** around expected drift
- **Application:** Position tracking, cumulative effects
- **Range:** [-n, n], bidirectional movement

**Unified Mathematics:**
Both homeworks use:
1. **Binomial coefficients** C(n,k) for path counting
2. **Pascal's triangle** for recursive structure
3. **Binomial distribution** for probability calculations
4. **2^n total trajectories** from binary choices
5. **Central Limit Theorem** for asymptotic behavior

**Key Transformation:**
```
S(n) = 2K(n) - n
```
This simple linear mapping connects the two perspectives while preserving the underlying combinatorial structure.

**Deeper Insight:**
The random walk (HW7) is not just a different view of Bernoulli trials (HW4)—it's a fundamental model in its own right, with applications ranging from finance to physics to computer science. The connection through binomial coefficients reveals the deep unity in probability theory: different phenomena share common mathematical structures.

**Educational Value:**
By studying both perspectives, we gain:
- **Combinatorial intuition:** Same counts, different interpretations
- **Probabilistic thinking:** From frequencies to displacements
- **Mathematical connections:** Pascal, Fibonacci, binomial theorem
- **Applied modeling:** When to use each framework

The beauty of mathematics lies in these connections—seemingly different problems revealing identical structures underneath.
