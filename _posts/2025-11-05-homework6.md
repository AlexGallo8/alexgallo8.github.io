## Introduction to Online Statistical Algorithms

Traditional "batch" algorithms for computing statistical measures like the mean and variance require storing all data points and making multiple passes through the dataset. In contrast, **online algorithms** (also called **streaming algorithms** or **incremental algorithms**) update statistics as each new data point arrives, requiring only constant memory and a single pass through the data.

This homework derives the mathematical foundations for online computation of the arithmetic mean and variance, implements these algorithms, and discusses their advantages from numerical analysis and computational perspectives.

<!--more-->

## Theoretical Foundation

### Problem Statement

Given a sequence of observations x₁, x₂, x₃, ..., arriving one at a time, we want to maintain:

1. **Running mean**: μₙ after n observations
2. **Running variance**: σ²ₙ after n observations

**Requirements:**
- Update statistics incrementally as each new value arrives
- Use O(1) memory (constant space, independent of n)
- Single pass through data
- Numerically stable computations

## Part 1: Online Algorithm for Arithmetic Mean

### Derivation of Recurrence Relation

**Goal**: Derive a formula to update the mean when a new observation arrives.

Let:
- μₙ = mean after n observations
- μₙ₊₁ = mean after (n+1) observations
- xₙ₊₁ = the new (n+1)-th observation

**Step 1: Write the definition of the mean**

After n observations:
```
μₙ = (x₁ + x₂ + ... + xₙ) / n
```

Therefore:
```
x₁ + x₂ + ... + xₙ = n·μₙ
```

**Step 2: Write the mean after adding xₙ₊₁**

```
μₙ₊₁ = (x₁ + x₂ + ... + xₙ + xₙ₊₁) / (n+1)
```

**Step 3: Substitute the sum from Step 1**

```
μₙ₊₁ = (n·μₙ + xₙ₊₁) / (n+1)
```

**Step 4: Simplify**

```
μₙ₊₁ = n·μₙ/(n+1) + xₙ₊₁/(n+1)

μₙ₊₁ = μₙ · n/(n+1) + xₙ₊₁/(n+1)

μₙ₊₁ = μₙ - μₙ/(n+1) + xₙ₊₁/(n+1)

μₙ₊₁ = μₙ + (xₙ₊₁ - μₙ)/(n+1)
```

### Online Mean Update Formula

**Recurrence Relation:**

```
μₙ₊₁ = μₙ + (xₙ₊₁ - μₙ)/(n+1)
```

**Alternative form (more intuitive):**

```
μₙ₊₁ = μₙ + δₙ₊₁/(n+1)

where δₙ₊₁ = xₙ₊₁ - μₙ (deviation of new value from current mean)
```

**Interpretation:**

The new mean equals the old mean plus a fraction of the "error" (deviation of new observation from current mean). The fraction 1/(n+1) decreases as more data accumulates, so later observations have less influence.

**Initialization:**

```
μ₁ = x₁  (first observation is the mean)
```

**Algorithm Pseudocode:**

```
function OnlineMean():
    n = 0
    μ = 0
    
    for each new observation x:
        n = n + 1
        μ = μ + (x - μ) / n
    
    return μ
```

## Part 2: Online Algorithm for Variance

### Derivation of Recurrence Relation

**Goal**: Derive formulas to update variance when a new observation arrives.

Variance has two common definitions:

**Population variance (biased):**
```
σ²ₙ = (1/n) Σ(xᵢ - μₙ)²
```

**Sample variance (unbiased, Bessel's correction):**
```
s²ₙ = 1/(n-1) Σ(xᵢ - μₙ)²
```

We'll derive the update formula using the **sum of squared deviations**:

```
Sₙ = Σ(xᵢ - μₙ)²
```

Then:
```
σ²ₙ = Sₙ/n        (population variance)
s²ₙ = Sₙ/(n-1)    (sample variance)
```

### Method 1: Welford's Algorithm (Most Stable)

**Step 1: Define the sum of squared deviations**

```
Sₙ = Σᵢ₌₁ⁿ (xᵢ - μₙ)²
```

**Step 2: Relationship between Sₙ and Sₙ₊₁**

We want to find: Sₙ₊₁ in terms of Sₙ, μₙ, μₙ₊₁, and xₙ₊₁

**Key insight**: When we add a new point and update the mean from μₙ to μₙ₊₁, all previous squared deviations change!

```
Sₙ₊₁ = Σᵢ₌₁ⁿ⁺¹ (xᵢ - μₙ₊₁)²
     = Σᵢ₌₁ⁿ (xᵢ - μₙ₊₁)² + (xₙ₊₁ - μₙ₊₁)²
```

**Step 3: Expand the first sum**

For i = 1 to n:
```
(xᵢ - μₙ₊₁)² = [(xᵢ - μₙ) + (μₙ - μₙ₊₁)]²
             = (xᵢ - μₙ)² + 2(xᵢ - μₙ)(μₙ - μₙ₊₁) + (μₙ - μₙ₊₁)²
```

Summing over i = 1 to n:
```
Σᵢ₌₁ⁿ (xᵢ - μₙ₊₁)² = Σ(xᵢ - μₙ)² + 2(μₙ - μₙ₊₁)Σ(xᵢ - μₙ) + n(μₙ - μₙ₊₁)²
```

**Step 4: Simplify using key property**

The sum of deviations from the mean is zero:
```
Σ(xᵢ - μₙ) = 0
```

Therefore:
```
Σᵢ₌₁ⁿ (xᵢ - μₙ₊₁)² = Sₙ + n(μₙ - μₙ₊₁)²
```

**Step 5: Substitute back**

```
Sₙ₊₁ = Sₙ + n(μₙ - μₙ₊₁)² + (xₙ₊₁ - μₙ₊₁)²
```

**Step 6: Express μₙ - μₙ₊₁ using our mean update formula**

From earlier: μₙ₊₁ = μₙ + (xₙ₊₁ - μₙ)/(n+1)

Therefore:
```
μₙ - μₙ₊₁ = -(xₙ₊₁ - μₙ)/(n+1)
```

**Step 7: Substitute and simplify**

```
Sₙ₊₁ = Sₙ + n·[(xₙ₊₁ - μₙ)/(n+1)]² + (xₙ₊₁ - μₙ₊₁)²

Sₙ₊₁ = Sₙ + n(xₙ₊₁ - μₙ)²/(n+1)² + (xₙ₊₁ - μₙ₊₁)²
```

**Step 8: Elegant final form**

Using δₙ₊₁ = xₙ₊₁ - μₙ (deviation before update):

```
Sₙ₊₁ = Sₙ + δₙ₊₁(xₙ₊₁ - μₙ₊₁)
```

This is **Welford's algorithm** - the most numerically stable method!

### Welford's Algorithm - Complete Formulation

**Update formulas:**

```
1. δₙ₊₁ = xₙ₊₁ - μₙ
2. μₙ₊₁ = μₙ + δₙ₊₁/(n+1)
3. Sₙ₊₁ = Sₙ + δₙ₊₁(xₙ₊₁ - μₙ₊₁)
```

**Variance formulas:**

```
σ²ₙ = Sₙ/n        (population variance)
s²ₙ = Sₙ/(n-1)    (sample variance, n > 1)
```

**Initialization:**

```
n = 0
μ = 0
S = 0
```

**Why this works:**

The term δₙ₊₁(xₙ₊₁ - μₙ₊₁) is always positive (or zero) because:
- If xₙ₊₁ > μₙ, then both factors are positive
- If xₙ₊₁ < μₙ, then both factors are negative
- The product is always non-negative

This ensures S (sum of squared deviations) is always increasing or stable, which is critical for numerical stability.

---

### Alternative Derivation: Using E[X²] - (E[X])²

**Variance identity:**
```
Var(X) = E[X²] - (E[X])²
```

**Online version:**
```
σ²ₙ = (1/n)Σxᵢ² - μₙ²
```

**Recurrence for sum of squares:**

Let Qₙ = Σᵢ₌₁ⁿ xᵢ²

Then:
```
Qₙ₊₁ = Qₙ + xₙ₊₁²
```

**Variance update:**
```
σ²ₙ₊₁ = Qₙ₊₁/(n+1) - μ²ₙ₊₁
```

**Warning**: This method is **numerically unstable** for large means or small variances due to catastrophic cancellation (subtracting two large, nearly equal numbers). Welford's algorithm is preferred.

import numpy as np
import matplotlib.pyplot as plt
from typing import List, Tuple

class OnlineStatistics:
    """
    Online algorithm for computing mean and variance using Welford's method.
    
    This implementation uses O(1) memory and provides numerically stable
    updates for streaming data.
    """
    
    def __init__(self):
        """Initialize the online statistics tracker."""
        self.n = 0          # Number of observations
        self.mean = 0.0     # Running mean
        self.M2 = 0.0       # Sum of squared deviations (S in derivation)
        
    def update(self, x: float) -> None:
        """
        Update statistics with a new observation.
        
        Parameters:
        -----------
        x : float
            New observation value
        """
        self.n += 1
        delta = x - self.mean
        self.mean += delta / self.n
        delta2 = x - self.mean
        self.M2 += delta * delta2
        
    def get_mean(self) -> float:
        """Return the current mean."""
        return self.mean
    
    def get_variance(self, ddof: int = 1) -> float:
        """
        Return the current variance.
        
        Parameters:
        -----------
        ddof : int, default=1
            Degrees of freedom (0 for population, 1 for sample variance)
        
        Returns:
        --------
        float
            Variance estimate
        """
        if self.n < 2:
            return 0.0
        return self.M2 / (self.n - ddof)
    
    def get_std(self, ddof: int = 1) -> float:
        """Return the current standard deviation."""
        return np.sqrt(self.get_variance(ddof))
    
    def get_count(self) -> int:
        """Return the number of observations processed."""
        return self.n
    
    def __repr__(self) -> str:
        """String representation of current statistics."""
        return (f"OnlineStatistics(n={self.n}, mean={self.mean:.6f}, "
                f"variance={self.get_variance():.6f}, std={self.get_std():.6f})")


class BatchStatistics:
    """
    Traditional batch algorithm for comparison (LESS STABLE).
    
    WARNING: This naive implementation stores all data and uses
    the numerically unstable formula: Var(X) = E[X²] - (E[X])²
    """
    
    def __init__(self):
        """Initialize the batch statistics tracker."""
        self.data = []
        
    def update(self, x: float) -> None:
        """Store new observation."""
        self.data.append(x)
        
    def get_mean(self) -> float:
        """Compute mean from all stored data."""
        if not self.data:
            return 0.0
        return sum(self.data) / len(self.data)
    
    def get_variance(self, ddof: int = 1) -> float:
        """Compute variance using naive (unstable) formula."""
        if len(self.data) < 2:
            return 0.0
        
        mean = self.get_mean()
        n = len(self.data)
        
        # Unstable formula: Var = E[X²] - (E[X])²
        sum_squares = sum(x**2 for x in self.data)
        variance = (sum_squares / n) - (mean ** 2)
        
        # Apply Bessel's correction if needed
        if ddof == 1:
            variance *= n / (n - 1)
        
        return variance
    
    def get_std(self, ddof: int = 1) -> float:
        """Return standard deviation."""
        return np.sqrt(max(0, self.get_variance(ddof)))
    
    def get_count(self) -> int:
        """Return number of observations."""
        return len(self.data)


def compare_algorithms(data: List[float]) -> Tuple[OnlineStatistics, BatchStatistics]:
    """
    Compare online and batch algorithms on the same data.
    
    Parameters:
    -----------
    data : list of float
        Input data sequence
    
    Returns:
    --------
    tuple
        (online_stats, batch_stats) objects
    """
    online = OnlineStatistics()
    batch = BatchStatistics()
    
    for x in data:
        online.update(x)
        batch.update(x)
    
    return online, batch

## Numerical Analysis Discussion

### Advantages of Online Algorithms

#### 1. Numerical Stability

**Catastrophic Cancellation Problem:**

The naive batch formula σ² = E[X²] - (E[X])² suffers from catastrophic cancellation when:
- Mean is large relative to standard deviation
- Computing difference of two nearly equal large numbers
- Loss of significant digits in floating-point arithmetic

**Example:**

Consider data near 10⁹ with small variance:

```
Data: [1000000000, 1000000001, 1000000002]

Naive method:
  E[X²] = 1.000000003 Ã— 10¹⁸
  (E[X])² = 1.000000002 Ã— 10¹⁸
  Variance = 1.000000003e18 - 1.000000002e18
           â‰ˆ 1e9 (wrong due to precision loss!)

Welford's method:
  Tracks deviations directly: (x - μ)
  Variance = 1.0 (correct!)
```

**Why Welford's Algorithm is Stable:**

1. **Works with deviations**: (xᵢ - μ) are typically small numbers
2. **No large number subtraction**: Updates use additions and small adjustments
3. **Compensated summation**: The formulation δ(x - μ_new) provides error compensation
4. **Always non-negative**: Sum of squared deviations S cannot become negative

---

#### 2. Error Propagation

**Floating-Point Error Accumulation:**

Every floating-point operation introduces rounding error: ε_machine ≈ 2.22 Ã— 10⁻¹⁶ (for double precision)

**Batch algorithm error growth:**

```
n operations → Error grows as O(√n)
Multiple passes → Additional error accumulation
```

**Online algorithm advantages:**

1. **Single pass**: Data processed once, no re-computation
2. **Compensated updates**: Welford's δ(x - μ_new) provides automatic error compensation
3. **Monotonic S**: Sum of squared deviations always increases or stays constant
4. **Bounded error**: Error doesn't accumulate as severely

**Error Bound Comparison:**

| Method | Relative Error Bound |
|--------|---------------------|
| Naive batch | O(nε + κε) where κ = (max\|x\|)²/σ² |
| Welford online | O(√nε) |
| Two-pass batch | O(√nε) |

For large κ (condition number), naive batch can be arbitrarily bad!

---

#### 3. Overflow and Underflow Management

**Overflow Problem in Naive Method:**

Computing Σxᵢ² can overflow even when variance is small:

```
Example: x ~ 10⁸, n = 10⁶
  Σxᵢ² ~ 10²² (exceeds double precision range: ~10³⁰⁸)
```

**Welford's Advantage:**

- Works with deviations (xᵢ - μ), which are typically O(σ)
- Sum of squared deviations S = Σ(xᵢ - μ)² ~ nσ²
- S grows linearly with n, not quadratically
- Much less likely to overflow

**Underflow Protection:**

- Small differences preserved in δ calculations
- Incremental updates prevent premature rounding to zero

---

#### 4. Computational Efficiency

**Operations per update:**

| Method | Additions | Multiplications | Divisions | Memory |
|--------|-----------|----------------|-----------|---------|
| Welford | 3 | 1 | 1 | O(1) |
| Naive batch (per point) | 2 | 2 | 0 | O(n) |
| Naive batch (final) | n | n | 2 | O(n) |

**Time Complexity:**

- **Online**: O(1) per update, O(n) total
- **Batch**: O(n) storage + O(n) mean + O(n) variance = O(n)

Both are O(n) total, but online has advantages:
- No need to store all data
- Results available at any time (not just at end)
- Can process infinite streams

**Space Complexity:**

- **Online**: O(1) - only three variables (n, μ, S)
- **Batch**: O(n) - must store all data points

---

#### 5. Robustness and Scalability

**Robustness:**

1. **Data Outliers**: Online algorithms handle outliers without recomputation
2. **Corrupted Data**: Can stop and resume without losing computed statistics
3. **Real-time Systems**: Provides current statistics at any moment
4. **Fault Tolerance**: If computation fails, partial results are available

**Scalability:**

1. **Big Data**: Can process datasets larger than available memory
2. **Streaming Data**: Natural fit for continuous data streams (IoT sensors, financial tickers, logs)
3. **Distributed Computing**: Easy to parallelize and merge statistics from different nodes
4. **Online Learning**: Foundation for incremental machine learning algorithms

**Parallel Online Algorithms:**

Multiple streams can be computed independently and merged:

```
Stream A: n_A observations → μ_A, S_A
Stream B: n_B observations → μ_B, S_B

Combined statistics:
  n = n_A + n_B
  μ = (n_A·μ_A + n_B·μ_B) / n
  S = S_A + S_B + n_A·n_B/(n_A + n_B) · (μ_A - μ_B)²
```

## Implementation Best Practices

### 1. Numerical Considerations

```python
# Always use floating-point arithmetic
self.mean = float(self.mean)  # Avoid integer division

# Check for division by zero
if self.n > 0:
    variance = self.M2 / self.n
    
# Handle edge cases
if self.n < 2:
    return 0.0  # Variance undefined for n < 2
```

### 2. Type Safety

```python
from typing import Optional

def get_variance(self, ddof: int = 1) -> Optional[float]:
    """Return variance or None if insufficient data."""
    if self.n < 1 + ddof:
        return None
    return self.M2 / (self.n - ddof)
```

### 3. Overflow Protection

```python
# For very large n, consider periodic rescaling
if self.n > 1e15:  # Approaching float64 precision limit
    self._rescale()  # Normalize and continue
```
